# 모아보라 — 디자인 문서

> Upstage 브랜드 기반 미니멀 디자인 시스템 정의.
> 구현 기준: Tailwind CSS 4 + shadcn/ui + AI Elements, 테마 토큰은 `app/globals.css`.

---

## 1. 디자인 원칙

1. **여백이 곧 위계다** — 그림자·구분선 대신 넉넉한 여백과 타이포 크기로 정보 위계를 만든다.
2. **한 겹 UI** — 카드 안에 카드를 중첩하지 않는다. 테두리는 요소당 한 겹만.
3. **아이콘·그림자 절제** — 장식용 아이콘과 그림자를 남발하지 않는다. 그림자는 `shadow-xs` 한 단계만.
4. **판정은 색으로 즉시 읽히게** — 지원 가능(초록)/확인 필요(회색)/자격 미달(빨강)은 어디서든 같은 색.
5. **AI는 과정을 보여준다** — 로딩 스피너 대신 실제 실행 단계와 Solar 추론을 실시간 노출해 신뢰를 만든다.
6. **하드코딩 금지** — 데이터가 없으면 가짜 값 대신 섹션을 숨긴다.

## 2. 컬러 시스템

### 2.1 브랜드 팔레트 (라이트)

| 토큰 | 값 | 용도 |
| --- | --- | --- |
| `--primary` | `#5b52ff` | Upstage 브랜드 퍼플. CTA, 활성 상태, 적합도 점수, 링크 강조 |
| `--primary-hover` | `#483fe6` | Primary hover |
| `--secondary` | `#f4f4f8` | 옅은 배경 (뱃지, 탭 활성 배경) |
| `--secondary-foreground` | `#322790` | secondary 위 텍스트 |
| `--accent` | `#eef1ff` | 퍼플 틴트 배경 (추천 사유 박스 등) |
| `--accent-foreground` | `#2d2088` | accent 위 텍스트 |
| `--muted` | `#f6f6f9` | hover 배경 |
| `--muted-foreground` | `#71717a` | 보조 텍스트 |
| `--border` / `--input` | `#e4e4e9` | 테두리 |
| `--destructive` | `#ef4444` | 자격 미달, 오류 |
| `--background` / `--foreground` | `#ffffff` / `#18181b` | 기본 배경/본문 |

### 2.2 다크 모드

- class 기반 (`next-themes`), 헤더의 토글로 전환
- 배경 `#0f0e17`, 카드 `#181724`, Primary는 한 톤 밝은 `#6c63ff`
- 시맨틱 컬러(emerald/destructive)는 `dark:` 변형으로 대비 보정

### 2.3 상태 컬러 규칙

| 상태 | 표현 |
| --- | --- |
| 지원 가능 | `bg-emerald-500/10` + `text-emerald-600` (dark: `text-emerald-400`) |
| 확인 필요 | `bg-secondary` + `text-muted-foreground` |
| 자격 미달 | `bg-destructive/10` + `text-destructive` |
| 마감 임박 (D-7 이하) | `text-primary font-semibold` |
| 마감 | `text-muted-foreground line-through`, 카드 전체 `opacity-50` |

> 색상 하드코딩 금지 — 반드시 테마 토큰(`bg-background`, `text-muted-foreground` 등) 사용.

## 3. 타이포그래피

| 용도 | 스타일 |
| --- | --- |
| 폰트 | Geist Sans (본문·제목 공용), Geist Mono (STEP 번호 등 코드성 라벨) |
| 페이지 제목 (h1) | `text-2xl~3xl font-bold tracking-tight` |
| 히어로 헤드라인 | `text-3xl sm:text-5xl font-bold leading-[1.18] break-keep` |
| 섹션 제목 (h2) | `text-xl~2xl font-bold` |
| 카드 제목 (h3) | `text-base font-semibold line-clamp-2` |
| 본문 | `text-sm leading-relaxed` |
| 보조·메타 | `text-xs text-muted-foreground` |
| 아이브로우(섹션 라벨) | `text-xs font-semibold tracking-wider text-primary uppercase` — pill·아이콘 없이 텍스트만 |

- 한국어 줄바꿈은 `break-keep`으로 어절 단위 유지.

## 4. 레이아웃

| 규칙 | 값 |
| --- | --- |
| 콘텐츠 최대 폭 | **전 페이지 `max-w-6xl` 통일** + `px-6 sm:px-8` |

| 헤더 | `sticky top-0 h-16` + `bg-background/80 backdrop-blur-md` |
| 챗 | `h-[calc(100dvh-4rem)]` 풀하이트, 내부 `max-w-4xl` |

## 5. 셰이프 & 엘리베이션

| 요소 | 곡률 | 그림자 |
| --- | --- | --- |
| 버튼·뱃지·입력 | `rounded-md` ~ `rounded-lg` | 없음 |
| 카드 | `rounded-xl` | 없음 (`border border-border`만) |
| 히어로·CTA 배너 | `rounded-2xl` ~ `rounded-3xl` | 없음 |
| 프롬프트 입력창 | `rounded-xl` | `shadow-xs` (유일한 그림자 허용처) |

- 카드 hover는 그림자 대신 `hover:border-primary/40` 테두리 변화로 표현.

## 6. 핵심 컴포넌트

### 6.1 AnnouncementCard (`components/announcement.tsx`)

공고 서비스의 시그니처 컴포넌트. 랜딩 히어로 예시에도 실물 그대로 사용.

```
┌─────────────────────────────────────┐
│ [카테고리] [자격판정]          D-14 │  ← 뱃지 행
│                                     │
│ 공고 제목 (2줄 클램프)              │
│ 주최기관                            │
│ 혜택: … (1줄 클램프)                │
│ ────────────────────────────────    │  ← border-t 푸터
│ 2026-09-04 마감      적합도 85점    │  ← Solar 점수 (있을 때만)
│ ┌─────────────────────────────┐     │
│ │ 추천 사유 한 문장 (accent 박스)│  │  ← 추천 사유 (있을 때만)
│ └─────────────────────────────┘     │
└─────────────────────────────────────┘
```

- 전체가 `<Link>` — 카드 어디를 눌러도 상세로 이동
- 마감 공고는 `opacity-50`

### 6.2 WorkflowLog (`components/workflow.tsx`)

AI 실행 과정 실시간 시각화. 챗과 동일한 AI Elements 사용으로 톤 통일.

- Solar 추론 단계(id=`reasoning`) → `Reasoning` 패널 (접기 가능, `max-h-60` + 최신 내용 자동 스크롤)
- 나머지 단계 → `Tool` 패널 (Upstage 제품 아이콘 포함 제목, 상태별 뱃지)
- 스트리밍 중 텍스트는 꼬리(clipTail) 기준으로 최신 부분 표시 + 블링킹 커서

### 6.3 UpstageBadge (`components/upstage.tsx`)

사용된 Upstage 기술을 명시하는 뱃지 (트랙 요구사항 가시화).

- Document Parse / Information Extract / Solar LLM / Studio Agents 4종 아이콘
- `bg-accent/60` + 제품 심볼 + 라벨, `truncate`로 좁은 화면 대응

### 6.4 기타

| 컴포넌트 | 역할 |
| --- | --- |
| `SearchFilter` | 키워드 입력 + 자격/마감 칩 토글 (드롭다운 없이 플랫) |
| `Hero` | 좌 텍스트+CTA / 우 실물 카드 예시 2컬럼 |
| `SiteHeader` | 로고 + 4개 네비 + 테마 토글 (프로필 아바타 없음) |
| `SiteFooter` | 한 줄 링크 + "JunctionX Korea 2026 · Upstage Track" + PoweredByUpstage |
| `Progress` | 프로필 완성도 — 라벨/% 양끝 정렬 + 바 |

## 8. 인터랙션 & 모션

- 전환은 `transition-colors` 위주 — 레이아웃 시프트를 만드는 애니메이션 금지
- 로딩: `Spinner`(primary) + 상황 설명 한 줄 ("Solar Pro 4가 분석하는 중입니다…")
- 스트리밍 텍스트: 블링킹 커서로 진행 중임을 표시
- 체크리스트: 클릭 토글, 완료 항목은 취소선
- 빈 상태: 점선 테두리 박스 + 원인 설명 + 다음 행동 버튼

---

## 9. 접근성 & 반응형

- 아이콘 버튼에는 `aria-label` 필수 (테마 토글, 새 대화 등)
- 좁은 화면: 뱃지 `truncate`+`shrink-0`, 툴 헤더 `min-w-0` 처리로 오버플로 방지
- 카테고리 탭은 모바일에서 가로 스크롤
- 그리드는 1→2→3열 반응형, 상세/프로필 2컬럼은 모바일에서 세로 스택
